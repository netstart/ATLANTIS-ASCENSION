## Classificação etária (questionário IARC)

Violência: fantasia, naves e máquinas sem sangue; sem violência contra pessoas. Sem linguagem imprópria, drogas,
apostas, compras de itens aleatórios (loot boxes) ou interação entre usuários. Compras no app: sim (cosméticos e
"Apoiar"). Anúncios: sim, só recompensados e opcionais.

## Segurança de dados (Play Console)

Nenhum dado coletado pelo app. Com AdMob ativo na 1.0: identificador de publicidade e dados de diagnóstico
compartilhados com o Google para anúncios (opcional, com consentimento UMP). Dados criptografados em trânsito pelo
SDK do Google. O usuário pode pedir exclusão desinstalando o app.
